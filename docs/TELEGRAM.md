# Telegram для учеников

Бот запускается отдельным процессом и работает с той же базой, что сайт. Ученик видит только свои работы после подтверждения учителем всех заданий. Разбор содержит ответ ученика, эталон учителя, объяснение, неопределённость и исправления; совпадающие фрагменты выводятся цитатами. Длинные результаты разбиваются на несколько сообщений.

## Подключение на этом компьютере

1. Создайте бота через [BotFather](https://t.me/BotFather) и сохраните токен у себя. Не отправляйте его ученикам и не добавляйте в Git.
2. Откройте локальный файл `.env` в папке проекта и добавьте строку `TELEGRAM_BOT_TOKEN=...`, вставив вместо многоточия токен. Не ставьте вокруг него кавычки.
3. В PowerShell из папки проекта перезапустите сервис:

   ```powershell
   pwsh -NoProfile -ExecutionPolicy Bypass -File .local-run/start.ps1 -Stop
   pwsh -NoProfile -ExecutionPolicy Bypass -File .local-run/start.ps1
   ```

   При наличии токена локальный скрипт запустит `python -m app.telegram_bot` вместе с сайтом. Нужен доступ этого компьютера к Telegram. Токен и учётная запись Telegram учителя сайту не нужны.

Для Docker после настройки `.env` запустите `docker compose --profile telegram up -d --build`. Профиль Telegram запускает один экземпляр бота. Не запускайте несколько процессов с одним токеном: они будут конкурировать за сообщения.

## Регистрация учеников

1. Учитель открывает класс на сайте и нажимает **«Создать код класса»**. Существующие листы, которые сайт связывает с этим классом, также привязываются на сервере.
2. Учитель передаёт код своим ученикам. Ученик открывает бота в личном чате и отправляет команду:

   ```text
   /link КОД_КЛАССА Фамилия Имя
   ```

3. В карточке результата учитель проверяет задания и нажимает **«Подтвердить всю работу»**. Можно также подтвердить каждое задание отдельно. После подтверждения ученик получит уведомление с кнопкой разбора.
4. Команда `/start` открывает профиль и подтверждённые работы ученика. На странице показано до пяти работ; стрелки открывают старые и новые. После изменения учителем задания работа временно скрывается до повторного подтверждения. Ученик может проверить привязку через `/status` и отключить её через `/unlink`.

В подтверждённой работе кнопка «Отправить сообщение ученику» отправляет текст и выбранные файлы непосредственно в Telegram, без повторной проверки и расходования листов. За один раз можно отправить до 10 файлов, каждый до 12 МБ и всего до 20 МБ. Если передача прервалась, сайт укажет, сколько частей уже отправлено; перед повтором проверьте чат, чтобы не продублировать их.

Имя и фамилия сравниваются без учёта регистра и могут быть переставлены местами. Для ФИО из трёх или четырёх слов нужен тот же порядок и состав слов. Если распознанное ФИО отличается, учитель может исправить его в карточке результата. Два ученика с одинаковым ФИО в одном классе не могут использовать одинаковую регистрацию; учитель может отвязать ученика в карточке класса.

Код класса общий: человек, который его получил, может зарегистрироваться под ещё не занятым ФИО. Раздавайте код только своим ученикам и проверяйте список зарегистрированных. Новый код отменяет старый для новых регистраций, сохраняя уже созданные привязки. При удалении класса регистрации и ожидающие отправки удаляются.

## Сеть и состояние

Боту не нужен входящий порт на компьютере: он сам обращается к Telegram. В локальной конфигурации сайт слушает только `127.0.0.1`, поэтому с телефона напрямую он не откроется. Для доступа с другого устройства нужно отдельно настроить защищённое соединение; не открывайте в интернет порты базы, Redis, хранилища и API. Классы и задания учителя синхронизируются с сервером по тому же аккаунту. При изменениях на двух устройствах сайт попросит выбрать версию вместо молчаливого перезаписывания; копия локальной версии сохраняется в браузере.

На карточке результата сайта отображается состояние отправки. Если бот выключен, ожидающие сообщения сохраняются. После нескольких неудачных попыток отправка отмечается как неуспешная; кнопка «Повторить отправку» повторяет доставку без нового запроса к ИИ. В редком случае обрыва после принятия сообщения Telegram повтор может создать дубликат.
