# Независимая проверка пилотной сборки

| Проверка | Результат и среда |
| --- | --- |
| Автоматические тесты | 101 прошёл. Подключён локальный PostgreSQL, конкурентные тесты работают в изолированных схемах. |
| Сквозной сценарий через сайт | HTTP-запросы прошли через прокси сайта к FastAPI, реальным PostgreSQL, Redis, RustFS и отдельному воркеру. Синтетический учитель зарегистрировался, вошёл, подтвердил тестовую подписку и загрузил два синтетических изображения. Проверены повторное платёжное подтверждение, защищённое чтение страницы, исправление ответа, перепроверка, подтверждение результата, списание одной проверки и удаление работы. В RustFS проверено исчезновение всех четырёх объектов работы. |
| Ограничения пилота | ASGI-проверка с изолированной схемой PostgreSQL, отдельным префиксом в Redis и хранилищем в памяти. Отклонены незарегистрированный в списке адрес и регистрация без кода. Проверены приглашение, вход, фактический лимит Redis, отправка задания в очередь, отдельный процесс рендера синтетического PDF и удаление результата. |
| Очистка непривязанных объектов | На временном бакете RustFS и схеме PostgreSQL пробный запуск сохранил объект, активная запись заблокировала удаление, а применение удалило только допустимый объект. Для проверки порога давности сдвигалось время в тестовом процессе. Условное удаление со старым ETag сохранило перезаписанный объект. |
| Оценка ИИ | Офлайн-проверка по эталонным транскрипциям дала 7 совпадений из 7. Это проверка выводов на заданных текстах. |

На RustFS найдено различие точности `LastModified` между выдачей списка и ответом на запрос метаданных. До исправления сравнение считало неизменённый объект изменившимся и пропускало удаление. После нормализации до секунд независимая проверка с настоящим RustFS и PostgreSQL прошла. Условие ETag при удалении сохранено.

В этих проверках использовались FakeAIProvider, тестовая оплата и синтетические работы. Живой Gemini, настоящий платёжный провайдер, Linux-контейнеры с TLS, внешний пилотный бакет и восстановление его резервной копии требуют отдельного прогона в целевой среде.
